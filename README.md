# 개형 배치 연습

실수 범위에서 인수분해를 모두 마친 식(문자식)을 보고, 그래프가 될 수 있는 개형을 모두 고른 뒤
고른 개형마다 x축을 끌어 알맞은 높이에 놓는 연습입니다. 시간제한과 랭킹은 없고, 기록은 선생님 페이지에서만 봅니다.

- 학생용: `사이트주소/`
- 선생님용: `사이트주소/teacher/` (비밀번호 필요)

## 출제 버전 (선생님 페이지에서 선택)

- 최고차항 양수만: 식을 (x − α)(x − β)² 처럼 a 없이 내고, 보기도 최고차항이 양수인 개형만 보여 줍니다.
- 섞인 버전: 식을 a(x − α)(x − β)² 처럼 내고, 위아래가 뒤집힌 개형까지 모두 보여 줍니다.
  a의 부호를 알 수 없으므로 양쪽에서 가능한 개형을 모두 골라야 정답입니다.

## 문제 구성

한 판 19문제, 무작위가 아니라 항상 같은 순서로 나옵니다: 이차 3 → 삼차 5 → 사차 11

- 이차: (x−α)(x−β), (x−α)², (x²+px+q)
- 삼차: (x−α)(x−β)(x−γ), (x−α)²(x−β), (x−α)(x−β)², (x−α)³, (x−α)(x²+px+q)
- 사차: (x−α)(x−β)(x−γ)(x−δ), (x−α)²(x−β)(x−γ), (x−α)(x−β)²(x−γ), (x−α)(x−β)(x−γ)², (x−α)²(x−β)²,
  (x−α)³(x−β), (x−α)(x−β)³, (x−α)⁴, (x−α)(x−β)(x²+px+q), (x−α)²(x²+px+q), (x²+px+q)(x²+rx+s)

인수분해 형태로는 이차 3, 삼차 4, 사차 8가지이고, 중근·삼중근이 어느 쪽 근인지에 따라 x축 위치가 달라지는 경우를 나누어 19문제가 됩니다.
출제 순서는 `src/game.html`의 `TYPES` 목록 순서를 따릅니다.

개형 보기: 이차 1개(포물선), 삼차 3개(극값 2개 / 평평한 점 / 극값 없음), 사차 4개(W자 / 평평→극소 / 극소→평평 / U자).
섞인 버전에서는 각각 위아래가 뒤집힌 개형이 더해져 2개·6개·8개가 됩니다.

허근을 갖는 이차식 인수가 있으면 극값의 개수를 식만으로 정할 수 없으므로, 그 차수의 개형이 모두 정답이 될 수 있습니다.
이때도 고른 개형마다 x축이 실근 구조(뚫고 지나감·접함·평평하게 지나감)에 맞게 놓여야 합니다.

x축 위치가 두 종류인 개형에는 x축이 2개 주어지고 "x축 위치가 2가지예요"라고 안내합니다.
두 x축이 모두 맞는 위치에 있고, 서로 다른 종류의 위치여야 정답입니다. 해당하는 경우는 다음과 같습니다.
- (x−α)(x²+px+q): 극값 2개 개형(극댓값보다 위 / 극솟값보다 아래), 평평한 점 개형(평평한 점보다 위 / 아래)
- (x−α)(x−β)(x²+px+q): W자(두 극솟값 사이 / 극댓값보다 위), 평평→극소·극소→평평(평평한 점보다 위 / 아래)

점수는 처음 제출한 답으로 맞힌 문제 수입니다. 틀리면 고쳐서 다시 내거나 "정답 보기"를 누를 수 있습니다.

## 배포 순서 (처음 한 번)

1. GitHub에서 새 저장소(예: `shape-place`)를 만들고, 이 폴더의 내용물(`src`, `netlify`, `build.mjs`, `netlify.toml`, `package.json`, `README.md`)을 올립니다.
2. 넷리파이 → Add new project → Import an existing project → GitHub → 새 저장소 선택 → Deploy
3. Project configuration → Environment variables → `TEACHER_PASSWORD` 등록 (Contains secret values 켜기)
4. Deploys → Trigger deploy → Deploy project 로 한 번 다시 배포
5. Make public 으로 공개
